About

I'm an AI engineer based in Kocaeli, Türkiye. I like owning a problem end to end: preparing the data, training the model, serving it through an API and building the screen people use.

I've worked in data, machine learning and e-commerce teams across three internships. In the latest one I built the system that writes product descriptions for brand catalogs on Trendyol with AI and sends every one of them to a person for approval. These days I work mostly on predictive maintenance for factories and on assistants built on large language models.

MaintAgent

An AI maintenance assistant for industrial machines. From sensor data it predicts the risk of failure in the next 24 hours and the part most likely to fail, and shows which signals drove each prediction. Next up is the LLM assistant that investigates a fault with tools and drafts the work order.

  • Microsoft Azure Predictive Maintenance data, processed with SQL on DuckDB
  • Multiclass LightGBM model for risk and the likely part
  • 13 automated tests, including one that checks the model never sees the future

Kocaeli Factory Intelligence

A predictive-maintenance dashboard for production lines. From machine telemetry it produces a 24-hour failure risk, an anomaly score and the first maintenance step for the shift. The model runs right in the browser.

Trendyol SEO description system

A Python system that pulls products from the Trendyol Seller API and writes SEO descriptions with OpenAI. Every description is checked against marketplace rules; a failing one is rewritten, and all of them go to a person for approval before anything is published.
